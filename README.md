# Kerry's Cyber Base

一个纯 HTML / CSS / JavaScript 的个人主页，当前包含：

- 全宽首页图片预留位
- 角色属性表
- 可上传、可翻页的“日常Report”
- 可自由创建、命名和调整展示宽度的私人相册
- JPG / HEIC / LIVP / 视频本地导入
- 访客只读、管理员通过 GitHub Token 发布共享内容
- 桌面与移动端响应式布局
- 深蓝、浅蓝、黑夜城市与感恩、圣诞、元旦、春节、清明、复活节主题
- 节日主题按日期自动切换
- 可编辑属性行与标签框
- 可编辑联系标签框、键和内容
- 加密的日常Report与只读访问口令
- 自动缩略图、发布重试与回到顶部按钮
- 首页背景、相册和头像的本地多选管理
- 删除内容时同步清理 GitHub 中不再使用的素材

## 打开网站

直接双击 `index.html`，或使用任意静态文件服务器打开。

局域网访问可双击 `start-local.cmd`。完整配置与发布方法见
[Config Tuturial.docx](Config%20Tuturial.docx)；
安全升级与数据保留步骤见
[Update Turorial.docx](Update%20Turorial.docx)。

## 替换首页图片与头像

管理员登录后，点击首页右上角“更换”可以上传一张或多张背景。点击“多选”后：

- 绿色勾选标记用于选择图片
- 只选择一张时才能点击“设置为封面”
- 选择一张或多张后可以批量删除
- 点击“退出多选”可以回到普通浏览状态

头像旁的“编辑头像”会打开头像历史窗口。可以一次上传多张头像，在多选状态下使用
某张头像作为当前头像，或批量删除历史头像。发布后的内容会写入 GitHub 仓库。

也可以把文件放进 `assets/avatar/` 或 `assets/hero/`，然后在
`site-data.js` 中填写：

```js
profile: {
  avatar: "assets/avatar/your-avatar.heic",
  heroMedia: "assets/hero/your-cover.heic"
}
```

通过 GitHub Pages 或本地静态服务器访问时，路径中的 HEIC 可以自动转换。

## 日常 Report

日常Report默认不在页面和顶部导航中显示。访客点击页面底部的“查看隐藏内容”，
输入只读访问口令后才能查看。管理员通过 GitHub Token 登录后会自动解密并显示隐藏栏目，
底部按钮会变为“口令编辑”，可由管理员设置或更换访客口令。

V0.3 使用信封加密：Report 文件由随机内容密钥加密，内容密钥再分别由访客口令和
管理员 GitHub Token 派生出的密钥包装。因此管理员改访客口令时不需要再次输入旧口令，
Token 和访客口令也都不会以明文写入仓库。V0.2 的旧版直接加密内容需要在同一浏览器中
使用一次旧访客口令完成迁移，之后即可使用 V0.3 的管理员自动解密。

点击“生活总结放映厅”左侧的上传区域：

1. 管理员登录后，点击左上角“< 总结册”打开抽屉。
2. 上传一个 `.pptx`，或一次选择多张按顺序命名的页面图片。
3. 上传后会自动提交到 GitHub，并发布给所有访客。
4. 可通过左右按钮翻页；在页码框中输入数字后点击“跳转”或按回车即可跳页。

浏览器无法原生播放 PowerPoint 文件，因此 PPTX 会在本地被渲染并保存为逐页 PNG 图片：

- 每个页面以一张完整图片展示，不再输出文字区块
- 保留页面顺序、图片和基本版面
- 不会保留 PPT 自带的切换动画

若需要 100% 保留 PPT 的视觉设计，建议在 PowerPoint 或 WPS 中将每页导出为 PNG、JPG、GIF 或 HEIC，再一起上传这些页面图片。GIF 会保持动画效果。

Report 页面图片使用 AES-GCM 在浏览器中加密后再提交到 GitHub。仓库中只保存
加密的 `.enc` 文件、加密索引和两份包装后的内容密钥，`content.json` 不包含幻灯片内容或明文口令。

## Gallery 相册

1. 管理员登录后，点击“创建相册”并填写名称。
2. 进入相册后上传 JPG、PNG、WebP、AVIF、GIF、HEIC、HEIF、MP4、WebM 或 Apple `.livp`。
3. 点击相册窗口底部的“多选”，然后点选一张或多张照片。
4. 只选择一张照片时，可以使用“设置为封面”将它设为 Gallery 主页面封面。
5. 选择一张或多张照片后，可以使用“删除”批量移除。
6. 在相册详情中使用“展示大小”滑块调整它在 Gallery 主页面的宽度，步进为 1%。

进入多选、勾选和取消勾选都只发生在本地，不会请求 GitHub；只有实际设置封面或删除时才会发布变更。
删除照片、视频、相册、首页背景、头像或 Report 时，网站会把不再被任何内容引用的文件
从 Git 树中一并移除，而不只是删除 `content.json` 中的索引。

## 主题与设备适配

顶部“主题”按钮可由所有访客使用，目前提供：

- 深蓝
- 浅蓝
- 黑夜城市：摩天楼从页面顶端延伸至远景消失点，楼体带有分层窗灯和招牌灯，
  中央街道向页面底部展开并带有路面反光
- 感恩
- 圣诞
- 元旦
- 春节
- 清明
- 复活节

手动选择会保存在当前浏览器的本地存储中，不会影响其他访客。节日主题会在下列日期
自动优先启用，并每分钟检查一次日期变化：

- 感恩：美国感恩节当天至随后周日
- 圣诞：12 月 24 日至 26 日
- 元旦：12 月 31 日至次年 1 月 2 日
- 春节：除夕至正月初七
- 清明：每年清明节气当天
- 复活节：耶稣受难日至复活节星期一

如果清明节与复活节日期重叠，会优先显示清明主题，仍可手动切换到复活节主题。

访客仍然可以在节日期间手动切换主题；当前页面会尊重这次手动选择。重新打开页面后，
若仍处于节日区间，会再次自动展示对应主题。节日结束后，会恢复此前手动保存的主题。

页面会根据浏览器视口宽度应用手机、平板和桌面布局。手机端会使用可展开导航、
单列卡片和自适应弹窗，避免横向滚动。

## 联系信息

管理员可以在页面底部点击“编辑联系”，添加或删除联系标签框，并在每个标签框中填写
“键 | 内容”格式的条目。发布后所有访客读取同一份联系信息。

## 页面版本

当前静态页面版本为 V0.3。

相册内容会通过 GitHub API 保存到 `content.json` 和
`shared/`，因此所有访客读取相同内容。

GIF、动态 WebP 和 APNG 会以原始图片形式播放；LIVP 中的动态视频会静音自动循环播放。视频能否解码仍取决于浏览器本身支持的编码格式。

## LIVP 说明

`.livp` 会在浏览器端作为 ZIP 包解析，并尝试提取静态照片与动态 MOV/MP4。能否直接播放 MOV 取决于浏览器对 HEVC/H.264 的支持；无法播放时仍可以在照片详情中下载提取出的原始文件。

## HEIC 说明

HEIC 和 HEIF 会在首次使用时按需加载本地转换组件，并转换为 JPEG 后显示。管理员发布后，转换结果会写入 GitHub 仓库的共享素材目录。

## 管理员与共享数据

- 访客只能查看，不能上传或删除内容。
- 点击右上角“管理”，使用拥有仓库管理员权限的 GitHub Token 登录后才显示编辑控件。
- Token 只保存在当前标签页的会话存储中，不写入源码。
- 所有发布内容由 GitHub 仓库统一提供，不同设备访问时会显示相同结果。
- 旧版本保存在浏览器 IndexedDB 中的数据可通过“导入本机旧内容”发布。
- 联系方式也可在管理员模式下编辑标签框、键和内容。

管理员面板中的“下载内容备份”可以下载 `content.json` 的本地副本。更新代码前，
仍建议从 GitHub 下载完整仓库 ZIP，以同时备份 `shared/` 中的素材。

## 图片加密的边界

日常Report的页面图片已加密。Gallery 和首页背景需要公开显示，因此任何访客在网页中
能看到的内容都无法同时保证“不可下载”。当前版本会生成 1600px 的高清缩略图用于
列表与封面加载，并在查看大图时加载原图。

如果需要 Gallery 与首页背景也只能由持口令者查看，需要再增加统一的私密媒体访问令牌，
或在云端使用私有对象存储和鉴权接口。
